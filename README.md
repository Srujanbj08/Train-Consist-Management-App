# Train Consist Management App

Train Consist Management App is a console-based Java application that simulates railway train consist operations such as bogie management, capacity tracking, cargo validation, sorting, searching, and safety compliance. The project is designed using a modular use-case-driven approach to demonstrate core Java programming concepts, data structures, algorithms, collections, streams, exception handling, and object-oriented programming. 

---

## Features

* Passenger and goods bogie management
* Train consist creation and tracking
* Capacity and cargo mapping
* Sorting and searching algorithms
* Stream API operations and filtering
* Regex-based validation
* Safety compliance checks
* Custom exception handling
* Performance benchmarking
